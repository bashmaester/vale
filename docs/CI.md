# CI / GitHub Pages

## What happens at the end of every turn

The working agreement is:

1. Finish the turn’s code + update `docs/HANDOFF.md` / `docs/CHANGELOG.md`.
2. Run `npm run build` so `index.html` is regenerated.
3. Commit and push to `arena/082e9ffd-vale`.
4. `.github/workflows/deploy-pages.yml` runs automatically and deploys the film
   plus the docs site to GitHub Pages.

The push is the trigger. There is no separate manual deploy command needed.

## Workflow

File: `.github/workflows/deploy-pages.yml`

Triggers:

- `push` to `arena/082e9ffd-vale`
- `push` to `main`
- `workflow_dispatch` (manual run from the Actions tab)

Permissions:

```yaml
contents: read
pages: write
id-token: write
```

Steps:

1. `actions/checkout@v4`
2. `actions/setup-node@v4` (Node 20, npm cache)
3. `npm ci`
4. `npm run build` — regenerates the self-contained `index.html`
5. **Validate no external assets** — fails if `index.html` contains
   `<script src>`, `<link href>`, or any `http(s)://` string
6. `npm run docs` — regenerates deploy metadata
7. Assemble `_site/`:
   - `_site/index.html` — the film
   - `_site/README.md`
   - `_site/docs/*` — handoff + architecture + changelog + CI + generated files
8. `actions/configure-pages@v5`
9. `actions/upload-pages-artifact@v3` with `path: _site`
10. `actions/deploy-pages@v4`

The deployed URL is exposed as `steps.deployment.outputs.page_url` in the
`github-pages` environment. For this repository it resolves to
**https://bashmaester.github.io/vale/**; the docs index is at
`https://bashmaester.github.io/vale/docs/index.html`.

## Generated vs human docs

Human-authored (edit these by hand):

- `docs/HANDOFF.md` — resume point for an interrupted session
- `docs/ARCHITECTURE.md` — system design
- `docs/CHANGELOG.md` — turn-by-turn changes
- `docs/CI.md` — this file

Generated by `npm run docs` (safe to overwrite):

- `docs/BUILD.md` — commit, branch, timestamp, file size
- `docs/DEPLOY_STATUS.md` — deployment table
- `docs/manifest.json` — machine-readable metadata
- `docs/index.html` — docs landing page with links + live README copy

`scripts/update-docs.mjs` reads the human docs but never rewrites them, so a
session can be interrupted without losing the handoff narrative.

## Local equivalents

```bash
npm run deploy:local   # build + docs
python3 -m http.server 8000 --bind 0.0.0.0
```

Then open:

- `http://localhost:8000/index.html` — film
- `http://localhost:8000/index.html?lab=1` — lab
- `http://localhost:8000/docs/index.html` — docs index (after `npm run docs`)

`_site/` is gitignored; CI recreates it from scratch.

## If Pages fails

- Confirm the repository’s Pages source is set to **GitHub Actions** (the user
  has already granted Pages deploy access).
- Check the Actions run log; the self-contained validation step is the most
  likely failure if a future change adds a CDN URL.
- Run `npm ci && npm run build && npm run docs` locally to reproduce.
- Re-run the workflow with `workflow_dispatch` after fixing.
